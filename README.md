# 塞西莉亚的图书馆

Windows 本地文档软件，以查看为主，保留少量基础编辑。程序显示名与项目名一致。

已确认的产品方向：

- 格式覆盖目标为 WPS 宣传的 47 种，不缩减为仅常用的几种。
- 主程序保持小巧，需要某类格式时再安装相应组件。
- 软件体积、启动速度和内存占用都需实际测量。
- 先完成文件打开及准确显示，再增加基础编辑。

当前开发版本为 0.1.2。46 项格式已有样本显示证据，包括六种 WPS 原生格式；剩余 `.ts` 的定义待核实。本轮修复浏览器预览结束后源文件未立即解锁的问题，减少 PDF 重复绘制，并调整表格存储和搜索时的内存使用。实际内存变化与检查范围见开发进度。

双击项目根目录的 `启动塞西莉亚的图书馆.cmd`；成品目录为 `dist/LightReader`。格式目标仍为 47 项，已有样本验证与未完成项分别记录。

项目启动入口会在首次运行或位置变化后自动维护 Windows“打开方式”候选登记；也可双击 `注册默认应用.cmd`，再在系统设置中选择需要默认打开的文件类型。

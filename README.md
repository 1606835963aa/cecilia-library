# 塞西莉亚的图书馆

Windows 本地文档软件，以查看为主，保留少量基础编辑。当前预览程序名为「轻阅」。

已确认的产品方向：

- 格式覆盖目标为 WPS 宣传的 47 种，不缩减为仅常用的几种。
- 主程序保持小巧，需要某类格式时再安装相应组件。
- 软件体积、启动速度和内存占用都需实际测量。
- 先完成文件打开及准确显示，再增加基础编辑。

已形成 0.1.0 可运行预览版。双击项目根目录的 `启动轻阅.cmd`；成品目录为 `dist/LightReader`。格式显示、基础编辑与占用证据见开发进度。

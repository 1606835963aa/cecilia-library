# 塞西莉亚的图书馆

Windows 本地文档软件，以查看为主，保留少量基础编辑。程序显示名与项目名一致。

已确认的产品方向：

- 格式覆盖目标为 WPS 宣传的 47 种，不缩减为仅常用的几种。
- 主程序保持小巧，需要某类格式时再安装相应组件。
- 软件体积、启动速度和内存占用都需实际测量。
- 先完成文件打开及准确显示，再增加基础编辑。

当前开发版本为 0.1.1，本轮改进阅读稳定性和资源释放。返回首页、进入组件页或切换文档时释放旧阅读视图；当前会话中的标签保留阅读位置、缩放和未保存的文本。PDF 连续翻页与缩放、表格查找和快速切换文件也补充了检查。实际内存变化与检查范围见开发进度。

双击项目根目录的 `启动塞西莉亚的图书馆.cmd`；成品目录为 `dist/LightReader`。格式目标仍为 47 项，已有样本验证与未完成项分别记录。

# 轻阅预览版

双击项目根目录的 `启动轻阅.cmd`。通过“打开文件”、拖入文件或最近文件列表开始阅读。多个文件可以在上方标签之间切换。

文字文档可缩放、搜索、复制和打印。表格可以选择工作表、翻行和翻列；搜索可以找到其他工作表里的内容。PDF 默认使用页面阅读，可翻页、输入页码和缩放；需要搜索或复制文字时点击“文字与搜索”。

ODT 使用办公兼容组件查看完整页面。Excel 加载项 XLA / XLAM 查看内部的静态表格数据，包括隐藏工作表。

TXT 和 CSV 提供编辑与另存为。CSV 的基础编辑使用文本形式；Word、Excel 原格式编辑及 PDF 批注尚未启用。

首次需要格式组件时，窗口显示下载量并提供安装按钮。组件安装后供离线查看；“组件”页面可以查看占用、安装和移除组件，也可以清理预览缓存。

DOCX 的“分页预览”使用办公兼容组件；表格也可以切换到分页预览查看打印布局。兼容组件处理完成后退出进程。

快捷键：`Ctrl+O` 打开，`Ctrl+F` 搜索，`Ctrl+S` 在编辑状态另存为，`Ctrl+W` 关闭当前文件。

格式与实测范围见 [开发进度](开发进度.md)。

# 塞西莉亚的图书馆 预览版

当前开发版本：0.1.1。

通过项目启动入口打开软件时，首次运行或项目位置变化后会自动维护 Windows“打开方式”的候选登记。也可双击 `注册默认应用.cmd` 手动更新并进入默认应用设置。

右键 PDF 等文件，选择“打开方式 → 选择其他应用”，在应用列表中查找“塞西莉亚的图书馆”。已经打开的旧菜单先关闭再重新打开；需要默认使用时再点“始终”。`.docx`、`.xlsx`、`.pdf` 等后缀分别设置。

登记沿用本项目的组件和设置。移动或更名整个项目文件夹后，重新运行一次登记入口。取消登记可执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\register-file-associations.ps1 -Remove`；已经设为默认的格式先在 Windows 设置中改回其他应用。取消后，启动入口也停止自动登记；再次运行登记入口可以恢复。

双击项目根目录的 `启动塞西莉亚的图书馆.cmd`。通过右上角的“打开”、拖入文件或首页的最近文件开始阅读，最近文件单击即可打开。多个文件在窗口顶部的标签之间切换，鼠标中键点标签可以关闭。

返回首页或进入组件页时，软件释放当前文档的显示资源，标签仍保留。重新点标签会加载文档，并恢复本次会话中的阅读位置和缩放；未保存的 TXT / CSV 编辑内容也保留。关闭有修改的标签时需要确认。

右上角依次是打开、最近文件、格式组件和外观。外观按钮在跟随系统、浅色、深色之间切换，文档纸张始终保持白底。

文字文档可缩放、搜索、复制和打印。搜索栏显示“第几个 / 共几个”，可以向上或向下查找。表格可以选择工作表、翻行和翻列；搜索可以找到其他工作表里的内容，切换工作表后从当前工作表继续查找。PDF 默认使用页面阅读，可翻页、输入页码和缩放，页面宽度随窗口变化；需要搜索或复制文字时点击“文字与搜索”。连续翻页和调整缩放时，以最后一次请求的页码为准。

ODT 使用办公兼容组件查看完整页面。Excel 加载项 XLA / XLAM 查看内部的静态表格数据，包括隐藏工作表。

TXT 和 CSV 提供编辑与另存为。保存期间继续输入的内容保留为新的修改，切到其他文件时不会被保存任务切回。CSV 的基础编辑使用文本形式；Word、Excel 原格式编辑及 PDF 批注尚未启用。

首次需要格式组件时，窗口显示下载量并提供安装按钮。组件安装后供离线查看；“组件”页面可以查看占用、安装和移除组件，也可以清理预览缓存。

DOCX 的“分页预览”使用办公兼容组件；表格也可以切换到分页预览查看打印布局。兼容组件处理完成后退出进程。

快捷键：`Ctrl+O` 打开，`Ctrl+F` 搜索，`Enter` / `Shift+Enter` 或 `F3` / `Shift+F3` 查找下一个 / 上一个，`Esc` 关闭搜索，`Ctrl+P` 打印，`Ctrl+S` 在编辑状态另存为，`Ctrl+W` 关闭当前文件，`Ctrl+Tab` 切换标签，`Ctrl+滚轮` 或 `Ctrl + / -` 缩放，`Ctrl+0` 恢复 100%，PDF 中 `PageUp` / `PageDown` 翻页。

格式与实测范围见 [开发进度](开发进度.md)。

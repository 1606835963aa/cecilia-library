# 开发进度与验收记录

版本：0.1.4 预览版。记录日期：2026-10-14。

程序显示名为“塞西莉亚的图书馆”。已完成基础阅读、按需组件和 TXT / CSV 基础编辑。各轮更新和验证范围分别保留。

## 开源准备（2026-10-15）

- 以 AGPL-3.0 开源。依赖中 WebView2 SDK 为 BSD-3、.NET 与 MimeKitLite 为 MIT、docx-preview 与 SheetJS 为 Apache-2.0、字体为 OFL-1.1，均可随 AGPL 程序分发；LibreOffice 作为独立程序按需下载调用。
- 新增 Inno Setup 安装包，约 6.8 MB，按当前用户安装。隔离目录静默试装通过：46 个后缀登记到“打开方式”，安装版打开 PDF、绘制进程随窗口关闭退出；卸载后程序目录、登记与开始菜单项全部清除。试装使用 `/SKIPRUNTIME=1`，自动下载安装 .NET 运行时需要管理员确认，尚未实际运行。
- 组件下载支持备用地址：docx-preview 许可证改为按提交编号固定；LibreOffice 增加官方归档站地址。备用地址的回退、指纹不符时继续尝试下一地址已加入核心检查；归档站本机无法连通，地址未实际下载核对。
- 报告中的本机绝对路径改为相对路径，`scripts/sanitize-reports.py --check` 加入自动检查。独立内容检查改为按项目目录解析相对路径，17 项通过。
- 新增 GitHub Actions：编译、核心检查、预览逻辑检查与路径检查；云端不下载办公兼容组件，相关一项记为跳过。

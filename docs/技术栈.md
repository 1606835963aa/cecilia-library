# 技术栈

选型日期：2026-10-12。已实现 0.1.0 预览版；实测进展见 [开发进度](开发进度.md)。

## 分工

| 层级 | 技术选择 | 负责的工作 |
|---|---|---|
| 主程序 | C# + .NET 10 LTS | 文件打开、组件管理、后台任务、缓存和本地保存 |
| 桌面窗口 | WPF | Windows 窗口、菜单、标签、对话框、拖入及快捷键 |
| 文档显示容器 | WebView2 Evergreen | 嵌入本地文档预览页面，显示本地 PDF |
| 预览页面 | TypeScript + HTML/CSS | 阅读界面、搜索交互和数据表格显示 |
| PDF 页面阅读 | Windows.Data.Pdf + WPF | 使用 Windows 原生能力绘制 PDF 与办公转换结果；文字搜索切换 WebView2 视图 |
| DOCX 快速预览 | docx-preview，候选 | 读取 Word Open XML 并显示为网页；复杂排版另行验证 |
| 表格数据读取 | SheetJS Community Edition，候选 | 读取工作表、单元格数据及已有计算结果 |
| 办公兼容组件 | LibreOffice 独立进程，候选 | 验证旧版 Office、WPS 系列、幻灯片以及复杂排版转换 |
| 本地配置 | JSON + 文件缓存 | 设置、最近文件和预览缓存 |

TypeScript 是开发时使用的语言，发布时编译为 JavaScript；终端用户无需安装 Node.js 才能使用预览页面。格式组件与页面资源安装到本地，日常查看不依赖网页服务。

## 选择依据

.NET 10 是长期支持版本，微软列出的结束支持日期为 2028-11-14。.NET 8 将于 2026-11-10 结束支持，因此正式项目采用 .NET 10。[微软支持政策](https://dotnet.microsoft.com/en-us/platform/support/policy)

WebView2 Evergreen 可让多个应用共享同一套运行时，从而减少重复占用。[微软分发说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution) 本地 PDF 可直接在 WebView2 中打开。[微软本地内容说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/working-with-local-content)

docx-preview 提供 DOCX 转网页显示能力，适合快速预览路线；采用前必须核对实际分页、字体、图片和表格。[作者仓库](https://github.com/VolodymyrBaydalka/docxjs)

SheetJS 社区版适合表格数据的读取与导出，不能作为完整排版和原样编辑保存的保证。官方把复杂样式、图表、公式计算等进一步能力放在专业产品中。[官方概览](https://docs.sheetjs.com/docs/) [公式说明](https://docs.sheetjs.com/docs/csf/features/formulae/)

LibreOffice 官方过滤器表列出多种 Office 与 WPS 扩展名，可作为兼容组件的验证候选。具体文件版本的兼容和转换显示质量仍需实测。[官方过滤器表](https://help.libreoffice.org/latest/en-US/text/shared/guide/convertfilters.html)

## 运行方式

主程序打开文件后根据实际内容识别格式，并选择已经验证过的组件。未安装组件时提供按需安装入口；组件安装完成后供后续离线使用。

纯文本、图片和 PDF 优先使用主程序及系统显示能力。DOCX 快速预览与表格数据视图使用对应轻量组件。需要复杂排版或旧格式兼容的文件，在后台兼容进程中处理，结果回到统一阅读窗口。

表格的数据视图与分页预览分别提供不同阅读方式。数据视图用于切换工作表和查看单元格；分页预览用于核对页面排版。两者都需要对应样本验证，不能用其中一种代替另一种验收。

兼容组件初期按一个可选办公引擎管理。未经验证，不承诺可以把 LibreOffice 按每个后缀或每类文档拆成独立的小包。

基础编辑另设模块。预览库输出的网页不能直接作为原文档的保存结果。普通单元格修改也必须验证对公式、样式、图表和其他工作表的影响，再决定保存实现。

## 体积与环境

小型发布包优先复用已有 .NET 桌面运行时及 WebView2。缺少公共运行时的电脑仍需安装依赖；所有格式组件装齐后的占用可能明显高于首次安装。

体积统计包括主程序、实际安装组件、缺失运行时的增量以及缓存。WebView2 及兼容引擎的子进程也计入内存，不能只记录主窗口进程。

项目内已准备 .NET SDK 10.0.401 和固定版本依赖。原生 PDF 接口已验证可用，目标平台为 Windows 10 2004 及以上。完整兼容组件位于项目独立目录，未安装系统办公软件入口。体积、启动与全部进程的占用见 [实测记录](开发进度.md)。

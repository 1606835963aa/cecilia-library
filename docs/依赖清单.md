# 依赖与分发

| 依赖 | 固定版本 | 用途 | 发布方式 |
|---|---|---|---|
| .NET SDK | 10.0.401 | 编译 | 开发工具，保留在 `.tools`，不进入成品包 |
| .NET Desktop Runtime | 10.x | 运行 WPF 软件 | 使用电脑已有运行时，成品依赖单列 |
| WebView2 SDK | 1.0.4258.31 | C# 显示容器 | 程序携带必要 SDK 文件及微软许可 |
| WebView2 Runtime | Evergreen，实测 154.0.4258.62 | 运行浏览器显示组件 | 使用电脑已有共享运行时 |
| Windows.Data.Pdf | Windows 自带 PDF API；SDK 引用 10.0.19041.57 | PDF 页面绘制 | 0.1.4 在随阅读启动和退出的内部进程中使用；与主程序共用 .NET 互操作文件，绘制引擎由 Windows 提供 |
| MimeKitLite | 4.18.1，MIT | 本地 MIME 网页归档解析 | 主程序携带解析库及许可 |
| docx-preview | 0.4.1，Apache-2.0 | DOCX 快速预览 | 可选 Word 组件 |
| JSZip | 3.10.1，MIT | DOCX 压缩包读取 | 可选 Word 组件 |
| SheetJS CE | 0.20.3，Apache-2.0 | 表格数据读取 | 可选表格组件 |
| LibreOffice | 26.2.6.3，MPL-2.0 / LGPL 等 | Office 分页转换 | 可选完整兼容组件；保留原包许可及其他文件 |
| TypeScript | 5.9.3 | 编译阅读页面 | 开发工具，用户无需安装 Node.js |

组件版本、官方下载地址、实际下载字节数和 SHA-256 在 [组件清单](../data/component-manifest.json) 中。安装使用完整下载、字节数核对、哈希核对和目录切换；不会把部分下载登记为已安装。

LibreOffice 通过官方 MSI 的行政解包生成本地引擎目录，不设置文件关联或系统办公软件入口。查看时使用应用专用配置和文件副本；宏关闭，Writer / Calc 链接更新关闭。配置缓存保留，转换进程完成后退出；文件锁串行保护相同配置目录的处理。暂不把复杂动画、公式重算或嵌入对象计入查看验收。

网页归档选用 MimeKitLite 的现有稳定包；其上游仓库正在规划拆分 MimeKit.Core，后续升级时核对正式 NuGet 包和迁移说明。
